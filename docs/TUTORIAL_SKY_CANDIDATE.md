# 新手地图：原天空与远山恢复候选

2026-11-14。本批有可见结果：在完整正式素材包的独立预览中，庭院及旧神殿下层的纯灰背景已能显示原包天空。建筑、地形和角色位置没有重排；旧下层的屋檐、孤立柱和结构开口仍然存在，不能称这些建筑问题已修好。候选尚未部署 Railway。

## 为什么确认这里漏了天空

原 `world/tutorial.wld` 是52字节AWLD，关联地图名与区块配置，不含可自行补出的天空尾部配置。实际模型请求来自原 `tables/zones.tbl` 的地图5区域记录，经区域选择及 `0x4c5b90` 的请求分支进入天空加载器。

当前正式包的251块地形、162份静态模型与1262条摆放都已在清单/传输范围内对齐，详见 `MAP_RELEASE_COVERAGE.md`。但当前 rendering 清单、场景清单及网页运行链都没有引用天空模型。实际浏览器背景是场景的 `96909d` 颜色；它不是自动找回的天空，也不是某张建筑纹理丢失时的替代图。

| 区域的 `skybox` | `model/scene/other_sky/tutorial_sky001.bdae` |

这些路径由源表、源模型材质和效果文件串起来，不因文件名看起来像天空就激活。

## 已核对的显示条件

`0x4c6438..0x4c6510`：优先用选中区域的非空名字，空名字回退基础区域194。远山名字为字符串 `0` 时走隐藏/释放分支；空字符串和 `0` 不是同一条件。地图5这五个已核区域最终均引用上表的两个模型。

原APK `assets/GameOptions.json` 的 GPU Default 声明 `ShowHillInSky=true`；`GPU_0M` 有关闭覆盖。原 `0x3bcbd0` 将布尔值写到配置 `+0xb4`，远山加载器 `0xa66de4` 消费它。该加载器还先检查一个全局字节：GOT `0x2507368` 重定位到BSS `0x2532ff9`，非零直接跳过。已有PHY工具把这条共享选择支路称为简化模式，这只是研究标签；本批没有观测原设备运行时该位或所有后续写入。候选限定为当前 `APK_Default`、未简化分支，不能宣称所有设备配置均已复原。

原模型加载成功后才取模型盒、挂入父场景并设置可见；失败时不能制造一个成功节点。本批浏览器先完整读入源几何、着色文件和纹理，缺文件或身份不符直接拒绝初始化，没有代用品。

源主天空为267顶点、528三角形，远山为84顶点、96三角形；保留源节点平移及索引。原主天空 `0xa64d0c` 使用 `450/max(abs(模型盒6分量))`，远山 `0xa66de4` 使用400，均有大于float32(0.1)的分支。两份源树是纯平移，变换前后最大绝对分量都由同一X/Z边界决定，因此本批的缩放不存在把Y平移忽略后改变最大值的问题。

原 `0xa63f40` 对已加载主天空、远山复制相机XYZ；候选沿用这一跟随方式，原节点矩阵仍在跟随根下面，不将模型固定到角色出生坐标，也不移动地形/建筑。

## 天空参数不等于新光照

本批执行原 `0x4be824` 构造函数及 `0x4c6e04..0x4c730c` 的天空专属写入块，与独立字段读取比较。没有执行或改写环境光、天气、雾距离、HDR/Bloom的现有参数。

- 构造出的天空距离状态是 `[0,50]`；不能拿天空对象另一份缓存的 `[40,40]` 冒充环境最终上传值。
- `sky_half` 非正时按原分支保留已有距离；实测区域195到194仍保持 `[42,43]`，没有重置成自编默认值。
- 颜色按原低字节在前的浮点转换写入，饱和度取对应原字段。
- 主天空/远山雾强度取基础区域相关字段，非正时分别为8和4。本地图源字段为0，并不表示将天空雾关掉。
- 原效果的数值状态转换与GL调用选择在隔离CPU中执行，远山确认是 `SRC_ALPHA, ONE_MINUS_SRC_ALPHA`；两者原效果均不写深度、不做深度测试、不裁背面。没有声称执行原GPU。

候选读现有环境已经建立的雾距离与颜色供原天空shader采样；不另建雾、光源、调色或天气。原shader及转换PNG留在私有目录，公开工具没有粘贴原shader正文。

## 网页适配及仍缺的原版部分

原天空曾有多批CPU队列/材质实验，但最终原GPU队列、所有设备profile及完整运行状态并未因此恢复。本候选明确使用Three.js把天空与远山先画进现有场景/HDR目标，再画建筑；这是网页绘制接线，不能说成已经重建原队列排序。GLSL关键字转换、纹理复用、纹理上传取向也属于浏览器桥接。

天空对象不加入行走地面、碰撞或点地拾取清单，不改变服务器逻辑。原来的建筑开口可以看到天空，但没有因此填墙、加地板、移动柱子或隐藏有问题的源模型。原建筑活动组合、未找到的原记录、70块原地形默认纹理缺口和升降台真实消息仍保留各自缺口。
