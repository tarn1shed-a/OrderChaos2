## 网页适配边界

- `deploy/source_avatar_state.mjs` 给新记录附加严格的 `sourceAvatar`，包含种族、性别、Model ID、草稿来源 SHA 和原外观整数。已存在的记录没有该字段时，保持原行为，不推定它们在原游戏是什么种族。
- 适配器在原存档模块第一次 `touch → flush` 前加入所选字段，避免先创建成旧模型再补写。继续使用原网页原子保存和恢复凭据。读取不迁移旧记录；未知来源或损坏字段拒绝，不悄悄落回精灵。
- 创建接口只从受信的草稿适配器选取原字段，不接收浏览器任意提交的模型、素材 URL、颜色或姿态。没有草稿适配器时不扩大正式创建范围。账号身份仍是此前已授权的网页试玩适配。
- 原网页角色视图和房间快照只追加经过校验的种族资料，不暴露恢复凭据、tokenHash 或私有位置表。已有角色视图保持原字段。
- `tools/source_species_worker.py` 对 SHA 固定的旧物理 worker 生成一个独立副本，仅在配置了本地校验资料时启用已核对的 `SourceSpeciesQueue`。旧 worker、原 127 份运行文件、原碰撞资源和原 CPU 指令不改。正式旧物理配置尚未切换到此副本。
- 每个演员按显式模型绑定自己的原动画范围，消息携带原模型身份；恢复位置保留身份，不允许重置请求偷偷换种族。停步、完成回调和混合仍用已核对原 CPU，未加入网页自定的动作优先级、装备或出生规则。
