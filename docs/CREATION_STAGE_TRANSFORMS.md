## 实际执行与网页承载的区别

`tools/creation_stage_probe.py` 执行原 ARM64 配置消费、相机创建、矩阵与移动计算。配置字符串由明确的原文件 provider 提供；分配/libc/单线程锁属于宿主服务。

TRS 实验使用原工厂创建的空节点，检查其位置、旋转、比例虚表与原模型基类一致。它仅用于执行变换，不假称 mesh 已加载。缺节点的对照保持 null；`originalModelCompleted` 始终为 false。方向光上传记录器只记录原 CPU 参数，不提供 GL 成功。

25 组原相机目标、500 帧输出已与网页步进逐帧对比；Three 视图矩阵误差限制为原大坐标下四个 float32 ULP。网页 GPU、纹理解码、现有动画宿主、单调时钟及全窗口缩放仍是浏览器承载，不能因此宣称原 Android 完整帧或像素级 1:1。

## 入口与资源边界

`deploy/creation_preview.mjs` 只在已有原种族页请求人类男女预览。它不调用角色变更接口、不写 localStorage 或存档，也不开放新的可玩种族。退出页面停止绘制，切换请求过期后丢弃旧模型；其它阶段不借用种族展示服。

`tools/creation_preview_delivery.py` 将冻结的 139 基础摆放、1 处神殿内侧、6 处双纹理石头，以及两套人类预览追加到私有包。已有 2899 个运行载荷、127 个审定运行文件、53 个物理宿主保持。完整原表、so、转储和审阅页没有新增到公开目录。原资源包只留本地，不上传 GitHub。

首次进图预载保持 **1089 critical / 450 background**。新增的选角资源按打开种族页才请求，不加入地图首载等待；源构造顺序保留，素材字节与图片准备使用有限并发。

当前联合画面为 25 块原地形、40 种模型、146 处静态摆放。其它追加候选有自己的交接，不能在尚未合并时计入这份包。天空原请求的两份 `whitepike_sky005.bdae` / `whitepike_skyhill005.bdae` 在现有包中没有找到，详见 `SELECTION_SCENE_SKY.md`；没有拿 tutorial 天空或新颜色填空。原实时区块中心、活动特效、其它种族/职业/已存角色预览、完整创角和原服批准仍未完成。
