# 人物与普通地图的共用绘制验收

2026-11-16 本批在隔离静态页面实际检查了同一套地图、renderer、scene、camera 与人类女性 Model32。页面没有账号、角色存档、WebSocket 或任务指令。本地审阅文字和按钮不加入游戏入口，也不表示正式创角权限已扩大。

人物复用自己的116节点、13网格、131属性/1928字节原姿态包，以及同一原材质、纹理与世界 Light 接线。原始65帧连续记录实际覆盖待机、前跑、右移和四段跳跃请求，共七个动作名；15段资料仍在，但不能据此称15段都已验过GPU。

实际 Chrome WebGL2 中，65帧共取得845个人物网格绘制观察。每次绘制后的当前程序、Light uniform读回与该次源输入一致，未发现着色器、GL或console错误。最初的显式QA相机过近，末帧人物离开画面；后续改到西侧审阅视角后可见完整身体。两次调整只改变独立QA相机元数据，没有改人物位置、大小、地图或游戏相机代码。

四格现有地图的122/256选定地形区块，实际产生1300次材质组绘制观察。20个活动缓冲与当前VAO、几何和代际相符；140个纹理引用中130个有真实GL纹理记录。余下10个恰为原分组`effectiveIndices=-1`的fallback槽，所选shader没有这些槽的取样；它们保留为空GL记录，不补写上传成功。法线属性也被当前地形shader优化掉，未伪造缓冲句柄。原图字节和解码尺寸另由固定资源闭包核验。

只读检查、实际释放、再次释放返回false、释放后观察被拒绝及整页重新有限重放均已实际操作并保留DOM收据。临时页面和三个本地静态服务随后关闭。九份根目录草稿/本地存档保护项逐字节保持；生产服务未因本批QA改变。
