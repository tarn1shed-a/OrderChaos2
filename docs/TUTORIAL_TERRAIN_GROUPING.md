# 新手地图地形最终材质组

本批修正的是已接入新手地图的地形贴图绑定，不增加地形、建筑、光照或碰撞，也不解决神殿结构开口和原活动平台缺失。

旧网页直接把遮罩裁剪后的 `effectiveIndices` 当作每小块最终材质。原客户端在后面还会合组：选择组代表，创建代表的材质，再把完整材质引用和五个采样器绑定复制给组内其余成员。成员自己的索引字段并不随这次复制改变。因而只核对成员字段，仍会漏掉原版实际使用的贴图和宏。

## 修正范围与实测

最终原材质与旧网页存在2178处绑定差异，其中干地1789、湿地389。旧网页118处首层裁剪为空，原最终代表材质没有此情况。早期诊断 `evidence-v1/samples-v1` 的1653处/75块不代表本批最终结果，保留但不得发布。

使用相同的原 PNG/MSK、相同明确的基础级双线性采样，重算696960点：84个小块存在大于1/255的颜色差。这个数表示采样代数差异，不表示84处都能从游戏视角看见；多数差异位于边缘，原设备的实时 mip/驻留与自适应 LOD 未恢复。

真实未改的网页构造器已核对全部251干地地块和105含水地块：2178组的实际采样器 URL、干地着色器分支、湿地宏和水参数均与原代表一致。所有顶点属性和有向三角形集合保持，边缘填充数量与原深度状态保持。这个 Node 检查不声称运行 GPU。

独立静态浏览器页使用既有正式地形/场景构造器和原 APK_Default 环境，固定研究时钟，不连接玩家服务器。五个原地块、93模型/569摆放；同一相机、同一光照逐次切换当前和原最终材质，实跑 WebGL 并记录实际材质 draw 回调和 URL。研究相机仅用于对照，不称原角色相机恢复。

## 集成接口

私有新命名空间：`/assets/source-tutorial-terrain-groups/overlay.json`，格式 `oc2-tutorial-terrain-native-material-groups-v2`。每个变化成员给出完整 `material`：原代表小块、effect24、宏、五个原 sampler 名称/原路径/转换 URL、原水参数及复制字段。

`tools/preview/tutorial_terrain_grouping_policy.js` 导出：

```js
const result = applyTutorialTerrainGroups(materials, policy, waterFloor);
const correctedMaterials = result.materials;
```

必须把同一个 `correctedMaterials` 提供给既有 `createSourceTerrain` 和 `createSourceWaterFloor`，只应用一次。返回的是完整验证后的克隆；原输入保持。对分阶段加载的同源 tile 子集也适用，返回计数是该子集计数；原全图计数由overlay固定核对。`waterFloor` 可在已加载时传入，以拒绝水参数/调色表不一致。

旧构造器把 `effectiveIndices` 用作采样输入，所以适配器将明确的最终 sampler 向量转到此兼容字段。**这不是声称原35127c复制了索引字段。** 原几何、遮罩、纹理、光照、水参数、Shader和存档全部沿用。新增引用的纹理已在旧完整包，追加包不复制或覆盖这些载荷。

正式接线由主代理审核负责；本批工具没有修改部署、游戏入口或生产服务。私有候选和截图留在忽略目录；公开只保留可复跑工具、适配代码及本文。
