## 确认并修正的预览错误

在 Z=20/34/48/62 四处，以相同原指令/静态场景和输入重放：旧规则均停在 X≈-2559.97998，撤去这项规则后均到 X≈-2563.33984。相邻两块地形边缘的65个原高程样点完全一致，没有重拼、补平或修改高度。

修改 `source_physics.py` 和 `source_swimming.py`，七块清单保留为碰撞研究缺口元数据，不再成为额外的64单位墙。源地块不存在时的限制保留；原查询、原形状、变换和接触响应继续执行。此地图当前没有 runtime `0x20000` 区块；没有为这个未出现的分支猜新规则。

核对原 `367800`、`363d30 → 353604 → a88674`、`a8b790`：加载状态、对象包围盒、具体形状与地表查询分别处理。Ghidra在负坐标处显示的整数转换容易误读；原指令是 `fcvtms`，确为向下取整，不应改成截断。`a8b790` 已合并链中各形状的边界，也不是只取第一形状边界的错误。原加载/查询没有使用本项目的缺口清单。

七块与邻块的84个边界样点全部不再被人为规则拒绝；短时原物理试走66处跨线。另18处没有在0.45秒夹具内跨线，其中有原形状命中、陡地和不合理的试验起点，**不能据此称18处都是游戏错误，也不能宣称全图碰撞已验收**。原 `god_greatbridge002.phy`（4924字节）和 `god_wall_06.phy`（4字节）在严格原读取接口下仍请求文件以外的字节；没有补零、改数量或生成替代碰撞。

另一个已知台阶（`god_bridge_step01` / ID253079520）在原消费者中仍会拦截特定路线；已记录具体形状和法线，没有加大跨台阶高度去覆盖原结果。后续须区分正常原碰撞、尚未解明的接触上下文和错误接线。

### 移动抖动

旧网页每帧平滑角色，直接使用每50毫秒到达的最新原相机结果；角色和相机不在同一显示时间，产生相对跳动。新 `source-frame-presentation.js` 将同一服务器帧中的角色/相机成对保存，在相同时间点显示两者；不预测未来位置、不重算碰撞，不新增相机弹簧。

100ms缓冲是明确的网页传输适配，**不是逆向出的原版插值参数**。停包时保持已收到的最后结果，不向墙内外推。服务端输入、速度、原相机CPU和物理不因这项修改改变。

实际浏览器对照：同一片平地、同方向行走，角色起点相差一个50ms输入步，均约60FPS；选取连续1秒稳定移动窗口，相机X单帧最大步幅约0.632→0.210，速度波动标准差约11.10→3.91。改善了这项显示抖动，不把它称为消除全部原相机/遮挡问题或提升FPS。

### 五官不见和身体色块

原 `oc2_elf_f_body_01_d.tga` 有完整脸部。原头部UV与预览完全相同；身体颜色图、法线、遮罩、皮肤遮罩及三张调色图，七张源图重新解码后与PNG的全部RGBA字节一致。原 `lt_pal_normal_vs.glsl`（SHA256 `081beacff05e2df94db740331cf0d4b6c7e1b2e8b4cc502ccffabccd3c9733a6`）直接将 `TexCoord0` 传给采样坐标，没有额外上下翻转。

场景材质已关闭网页翻转，旧角色路径却保留 `TextureLoader` 的默认 `flipY=true`，导致颜色、法线及遮罩一起取错行。新 `source-character-textures.js` 只在独立角色纹理副本上关闭该翻转，保护共享纹理；没有改原像素、UV、肤色或光照。

实际同角色、同位置、相机状态完全相同的前后截图，五官恢复，手臂和腿部的大块错色消失。原调色板、光照方向、gamma桥接和完整角色材质状态仍有历史适配，不能因此称角色已经像素级1:1。

## 文件与复用规律

- `temple_ambient.py` / `native_temple_ambient.py`：原环境RGB生产和提交核对，区分CPU结果与真实GPU状态。
- `source_physics.py` / `source_swimming.py`：仅撤回无源依据的整块禁行；元数据缺口不等于原版墙。
- `source-frame-presentation.js` / `connect_frame_presentation.py`：独立网页时间配对，不冒作原客户端插值规则。
- `character_orientation.py` / `source-character-textures.js` / `connect_character_orientation.py`：先核原UV、源图行序，再只修显示上传方向；颜色/法线/遮罩须一致。
- 所有接线器固定前一阶段SHA，发现不同版本或重复接线时拒绝。旧阶段测试核对历史输出，新阶段单独核对最终结果，不靠修改旧预期掩盖回归。

完整有界记录：`analysis/raw/temple-ambient-20261112/`。继续工作应优先复现具体剩余接触/纯色像素及绑定，缺证据留缺口，不用自创功能或材质填满地图。
