# 神殿暗区：材质、光照图与原始 mip 核对

2026-11-12，基线 `71e4e38`。本轮范围是 `god_temple01..05` 五个原模型、8 条原摆放，重点观察神殿 04（实例 `715733704`）。**恢复了原始 mip 和采样请求，但相同近景的暗墙没有因此变亮，不能把它称为偏暗主因已修复。** 没有提高曝光、环境光或改色。

## 文件及关联已经确认的部分

- 五份 BDAE 的 29 个材质槽与当前转换资料相同；位置、法线、UV0、UV1、索引、primitive 分组逐项相同。
- 8 个实例重读原槽 0 DAT，ID、图页及四个 UV 浮点参数与预览相同。没有借槽 1，也没有重新摆放模型。
- 两个原效果 `ut_lightmap_solid.bdae`、`ut_cull_lightmap_solid.bdae` 的两个 profile 都是相同的 LIGHTMAP 算式，保留各自剔除状态；材质 sampler 四项 FF 跳过覆盖。FX 中默认纹理为空，不会凭其 U/V 记录覆盖后来加载的图页。
- 神殿 03/04/05 原模型确实引用 `texture/god_all_l.tga`，不是预览自行换成低清图；01/02 使用分开的墙、柱、台阶等纹理。不能从 `_l` 名字推断当前模型选错。
- 17 张唯一颜色图、7 张唯一光照图，共 24 张；原 PVR 均为二维 POT ETC1，完整层级共 230 层。原第 0 层解码与旧 PNG 全部 RGBA 字节相同。

神殿 04 的原记录为 `world/tutorial/lightmap/-41_2.dat` 中 ID `715733704`，槽 0 图页 `texture/lightmap/tutorial/lightmap/-41_2.tga`，UV 参数约 `(0.439797014, 0.008799590, 0.057617199, 0.230469003)`。它只有一个材质、一个部件和一条绑定，不受上一轮部件顺序错误影响。

## 原代码怎样决定采样

固定 ARM64 库 SHA256：`77f449f2100a4717578e282bb04f1f8fff25d25c7bfa461d7d39ee49d1cb8ca4`。地址是该样本的研究标签。

| 原入口 | 核对内容 |
| --- | --- |
| `0x13d7c38 → 0x13d7d8c` | 在原纹理字节上实际执行头读取/校验，输出 type 1、format 0x34、宽高和 mip 标志。流读/seek/长度为明确接口，不把物理读取器的布尔返回用于此处的字节数返回。 |
| `0x143e4d8..0x143e4e0 → 0x144120c..0x1441274` | 原管理器初始 +0xf8=0x22，bit5=1；原加载器保留这些 PVR 的 mip 标志，再交给构造器。两个有界片段实际执行，完整构造/加载过程没有执行；不是仅因文件有层级就假定加载器必用它。 |
| `0x146d6f8..0x146d914`，属于 `0x146d4a8` | 执行原构造中的采样位初始化及 POT 地址处理。带 mip 时 min=3（Linear Mipmap Nearest），mag=1（Linear），POT 地址为 Repeat；不是只读初始常数就略过后面的地址修改。没有声称执行完整图形构造。 |
| `0x3bb830` 的命名配置读取 | `Anisotropy` 默认 4 写入 +0x5c；TextureSkippedMipmaps/LightmapSkippedMipmaps 默认 0 写 +0x90/+0x94；EnableSkipMoreMipmapLevel=false 写 +0xb7。字段和原名称/完整例程字节核对，默认值另外由原配置选择器执行核对。 |
| `0x5513b8..0x5513d0` | 原颜色图路径读取 +0x5c，转为浮点，调用 `0x146f728`。 |
| `0x328e9c..0x328eb4` | 原地图光照图路径也读取 +0x5c，调用同一 setter；不能假定光照图只用初建各向异性 1。 |
| `0x146f728 → 0x14320d4` | 实际执行原 setter 和 GL 参数消费器，记录 min=9985、mag=9729、U/V=10497、各向异性 min(4,能力上限)。不支持扩展时不发各向异性调用；请求 0 被钳到已存在的 1 时不标脏、不重复调用。 |

明确采用用户要求的 APK_Default：Anisotropy=4，三项 mip 跳过/低端额外跳过为 0/false，DisableAnisotropy=false。完整文件 mip 可用时 min=3；原“mip 尚不可用”输入另测会降为 Linear。这里不伪造原 GPU 上传成功或原 Android 缓存状态。GL 调用在 CPU 探针中只是参数记录；能力是明确输入。

旧网页仅导出第 0 层 PNG，让浏览器生成后续层，使用 Linear Mipmap Linear 和最多 8 倍各向异性。新路径保存每层原 ETC1 块的源偏移、长度、SHA，并分别解码成 RGBA，再按原层序上传；不会重生成 mip。230 层 RGBA 共 30,539,744 字节，原图块与解码结果都能逐层校验。

这是浏览器接口适配：原客户端可直接上传压缩 ETC1，网页此处上传解码后的 RGBA；不把它冒充原 GPU 逐位执行。Three 当前版本会在 LinearMipmapNearest 下跳过各向异性设置，适配仅在这一批纹理的上传回调中补发独立请求，宿主实际查询 min=9985、mag=9729、Repeat、各向异性 4。没有修改渲染器全局代码，也没有改其他模型的共享纹理。

## 画面结论及缺口

隔离端口 8873、临时角色在原地形支撑 `(-2600,132.349991,180)`；这是验收位置，不是原出生点。原相机稳定位置 `(-2600,135.155640,185.832123)`，yaw=0、pitch=355、距离约 5.8。1280×720 前后相机矩阵完全相同。

近处暗墙区域 `(450,140)..(820,300)` 平均 RGB 前后均约 `(10.50,10.02,10.26)`；右柱及地面控制区也逐像素相同。屏幕下左坐标 (0.7,0.7) 的场景 RGB 均为 `(12,9,9)`，Bloom 为 0。这排除了“旧自动 mip/过滤是这个近景暗墙的主要原因”，不能从没有变亮反推出所有距离下的采样都已相同。

临时分项诊断排除隐藏衣物后，实际命中神殿 04 的实例 `715733704`/材质 0。在同一 (0.7,0.7) 点分别绘制各乘数，颜色图为 `(77,85,87)`、原图页为 `(22,22,30)`、顶点光照按除以 4 编码读回 `(116,76,58)`。将其还原为约 `(1.820,1.192,0.910)`，独立计算 `颜色RGB8 × 图页RGB8 / 255 × 顶点光照`，约得 `(12.09,8.74,9.31)`，与场景读数 `(12,9,9)` 在 8 位采样误差内一致。原 `ut_common_fs.glsl` 确实作颜色图×lightMap×vColor0；`ut_common_vs.glsl` 的 vColor0 含全局模型光照和颜色远近增益。没有找到可凭据增加一个常量倍率的源分支。

这闭合的是**当前源资源预览的暗色产生阶段**，不是同位置原 Android 完整帧比对。临时分项诊断、实际双连接移动及恢复结果保存在本轮忽略目录。原分项诊断的射线会命中 `visible=false` 的角色衣物，不能据此误判神殿材质类型；本轮临时诊断跳过不参与绘制的对象，游戏画面和碰撞不因此改变。原版完整帧/活动材质与灯光状态仍未观察；是否还缺其他亮度叠加，保留未知，不给原图手调补光。

## 文件结构与复用方法

- `tools/temple_sampling.py`：校验原模型/FX/DAT，解析原层级并导出完整 mip、策略和证据报告。
- `tools/native_temple_sampling.py`：原头读取、构造片段、两条各向异性路径和 GL 参数消费；显式标出流、能力与 GL 记录接口。
- `tools/preview/source-temple-sampling.js`：只替换这 8 条原摆放的颜色图/图页采样，旧 UV、灯光和其他模型不动。
- `tools/connect_temple_sampling.py`：对上一阶段有界接线，重复执行拒绝，不覆盖旧素材。
- 本地 `source-temple-sampling/policy.json`：模型 SHA、原纹理名、每层源块/解码字节、采样请求和实例图页关联；`*.rgba` 为整条解码 mip 链，`audit.json` 为完整研究记录。
- `tools/preview/temple-sampling-gpu-qa.*`：独立开发验收页，检查三色整数 LOD 0/1/2 与实际采样状态，不进入游戏界面。不据此推断不同驱动的分数 LOD 或 Android 像素结果。

后续顺序：先分清“选错原文件”“图页/UV 关联错”“采样路径不同”“原图及当前光照相乘本来就暗”；验证一项排除一项。特别是 FF 代表跳过，不代表 Nearest；图页替换只换资源，不能把占位图 sampler 顺便套到新图页；只有第 0 层相同不代表整个 mip 链相同。

新增 8 项检查、原部件绑定 8 项、隔离游戏/双连接/存档 12 项回归；无原资料副本 3 通过、5 明确跳过。原图片/完整表格/原生转储/截图/私有角色只留本地，另打可校验素材包。自动任务 2 保持 PAUSED。

实际按 A 移动、D 反向移动，两端看到相同位置与 `grounded=true`，高度均为原地形的 132.349991。刷新后位置/高度与刷新前一致，两端无 warn/error；没有声称路径精确返回起点。主角色存档和49个旧演示角色保持，全部旧素材逐文件 SHA 保持。

本地素材包：`backups/tutorial-temple-sampling-source-assets-20261112.zip`，含逐文件 SHA 清单，并做 ZIP CRC/逐文件 SHA 核验；不含存档、恢复码或截图。完整证据与截图：`analysis/raw/temple-sampling-20261112/`。原资料齐备时可使用 `tools/temple_sampling.py --runtime <忽略的预览目录> --output <忽略的输出目录>` 重建，`tools/connect_temple_sampling.py --runtime ... --export ...` 仅用于上一阶段，已接线的目录不可重复执行。
