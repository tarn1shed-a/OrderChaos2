## 黑屏原因和原入口

正式站的职业图标会切换原职业名称、说明，并能继续到外观页；旧网页预览模块却只接收种族页，切到职业页还会隐藏画布。因此按钮有效和没有人物同时发生。这是网页接线缺口，不是源模型全部丢失。盖住背景的黑矩形是原UIComponent要求隐藏的`mc_bounds`测量对象，已按原方法隐藏。

原`CharacterChooseRace/Class/Part.swf`分别传`Character_EnterPanel(0/1/2)`。原ARM64 `6fed70`依次调用`541424`选相机、`542da4`换模型；相机组表为`[3,3,2,2,0,0,1,0]`。种族和职业页共用组3，外观页组2，不能把相同镜头和展示服贯穿三页。45组原请求及15组原相机选择已执行核对。
