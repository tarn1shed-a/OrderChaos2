# 任务窗口的样式加载修复

2026-11-16。正式网页的安全策略为 `style-src 'self'`。旧任务窗口和追踪模块在运行时插入内联 `style`，在实际浏览器中没有应用：任务窗口为 `position:static`，高度1233像素，而视口为720像素。SVG、正文和按钮仍在DOM中，点击位置却与画面不符。不能仅凭DOM里有“确定”判断任务可操作。

修复只改变网页样式的加载方式：原布局规则逐字移入同源 `quest_ui.css`、`quest_tracking.css`，按正确CSS类型登记到交付清单，初始化等待加载成功。原三份字体通过FontFace加载，仍使用原 `fontBaseURL` 和文件名；失败清理未安装的字体与窗口，释放时只删除本实例字体。没有放宽安全策略，没有改变原SVG、文字、字体、位置计算、AS分支、任务目标、奖励或服务器规则。

父级在独立Linux容器、全新验收角色实际测试：点击NPC2079打开原461《第一印象》，接取后追踪0/4，走到四处原齿轮逐次1/4、2/4、3/4，再切为“与工程师交谈。”，返回原NPC并经过原两阶段确认，领取金币9、经验512、Favor5、物品20028×1。另一角色保持独立进度。最终布局为fixed且高度等于720像素视口；原字体族和字号保持。测试没有接触用户或生产存档。

上述经验仍保存在既有独立任务账本，不接入旧试玩每60经验升级公式。461的兼容执行是用户已授权的重建层，不是找回原服务端；208和202主线仍未接通，不补写缺失对白或批准条件。

同轮NPC头标研究已实际浏览器显示原可接、未完成、完成三图，并在独立任务页随实际query/state切换。修正了Three对自定义Vertex属性未自动生成包围球的适配遗漏；原几何、深度和高度未改。图标、GLSL和RGBA仍留私有目录；本次样式发布不包含该未打包的NPC标记候选，也不声称所有原NPC资格或名字缓存调度已恢复。
