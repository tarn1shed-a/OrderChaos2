## NPC与怪物归组

原静态关系是：creature_proto→creature_appearance→display→Model，必要时再连extra外观、装备、身体和动作。creature_spawns提供表内摆放候选，但不能单独证明实际会话中的活动演员或任务资格。

现有表含5703条模板、5696条appearance、415条Model配置，44个地图编号中有12917条存储的spawn记录。5671条默认外观引用可沿链解析到285个模型路径，其中231个路径供多个模板共用。另25条默认引用存在缺口（包括display为0的情形），不自行补模型。

因此先按身体/装备/材质/动作类型恢复共用构造器，再以原模板数据组装，比逐NPC独立实现更合适。285个模型路径不是285个已恢复NPC，12917条spawn也不是已批准出现在网页里的演员。实际外观覆盖、phase、出现条件、任务批准和运行时消息必须另核。

角色同样采用一个共用几何与采样核心，按原身体、骨架、材质、挂接方式区分配置；相关记录见 `CREATION_SHARED_GEOMETRY_CORE.md` 与 `CREATION_BODY_PLAYBACK.md` 的对应候选交接。结构盘点通过不能代替GPU、角色可玩和地图路线验收。
