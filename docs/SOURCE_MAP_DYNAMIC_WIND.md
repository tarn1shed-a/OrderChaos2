## 实现边界

- `tools/scene_dynamic_wind.py`：原模型/FX/UV/采样/图集读取，固定库和函数SHA；原质量、时钟、矩阵消费者执行；只导出这一模型和已核对默认分支。8份输出与重建逐字节一致。
- `tools/preview/source-dynamic-wind.js`：验证原资料和程序SHA，连接原代码块、速度及TexCoord2；每实例图集克隆后重新绑定独立uniform，逐次绘制强制更新。旧零速/灰度路径保持。
- `tools/connect_dynamic_wind.py`：只修改隔离预览的地图入口、额外UV接线、已核实透明/双面表及本轮材质接口；13份接入重放一致，重复接入在写入前拒绝。
- `source-map-dynamic-wind/`：本地转换命名空间，包含原模型/纹理、manifest、selection、baked-lighting、audit及原wind-block.glsl。完整资料不上传GitHub。

宿主时钟按浏览器模块初始化时的单调时间记录起点，再复现原普通时钟转换；没有臆造一个原安卓运行时刻。不同浏览器或刷新后的摇动相位可以不同；这不影响已核对的原周期/幅度。原完整暂停/恢复事件、改速写入的生命周期、设备覆盖/保存配置、材质宏的全部变化、原GPU精度和纹理mip/滤波仍有缺口。缺口不靠自造状态补齐；源数据标注hostOrigin及fullOriginalFrameRestored=false，不将时钟适配称为原现场恢复。
