## 一个核心，数据驱动

`creation_geometry.mjs` 使用同一个 `creation_batch/geometry_core.mjs` 构造身体、衣物、骨架、材质和武器，不按职业复制renderer。原核心只增加可注入的验证/采样接口；旧默认分支保持。

`stage_guard.mjs` 同时用于服务器准备和浏览器构造：Class消费摘要绑定的原policy；普通Part使用既有v6守卫和自己的literal骨架，不借Class效果例外。未证明的Part特殊材质仍拒绝。采样能力来自实际存活的WebGL2上下文，不能用离线夹具冒充GPU。

新的 `manifest-stages-v3.json` 显式选择这条管线。旧六份预览保留原文件和原工厂，缺少新profile的旧素材包照常使用旧入口；新的十份人物只在进入相应页面时加载，不把选角素材放进地图进入门槛。

私有完整包保留旧3873个载荷逐字节不变，追加313个载荷。代码没有导入本地存档，没有修改世界入场、职业技能或角色创建权限。
