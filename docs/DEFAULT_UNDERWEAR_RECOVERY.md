## 贴图替换与身体遮挡

原 `0x325ce0` 先检查槽、采样器编号、字符串是否非空以及该槽是否已有模型，再建立 `texture/<stem>.tga` 请求。实际执行核对：

- 空覆盖字符串不发替换请求。
- 没有槽位模型时，即使传入非空字符串也不发请求。
- 有槽位模型且字符串非空时，三个编号分别选择原 `texture`、`normalMap`、`maskMap` 名；原 `_briefs_01_d` 请求准确落到该衣物模型，不是自动给整个身体换成一张无短裤的图。

`0x325e5c` 在这次实验里是参数记录边界，显式返回的接受值只用于观察后续字符串记录，**没有执行原材质/GPU 创建**。格式化和 C++ 字符串储存是宿主适配，未称原 Android 现场。完整原替换器的遍历、资源成功生命周期不在本轮接入范围。

原 `0x321350` 的两个部位计数也已实际执行：只增加一个通道保持身体；两个通道同时为正才请求隐藏；撤去任一通道后请求恢复。场景挂接/移出是记录边界。空槽修正保留所有原身体部位，不把蓝色图案当作一个可删的“裤子网格”。

本轮没有将这些有界计数实验扩称为完整装备系统。当前布甲、鞋靴等非零装备仍沿用此前明确标记的网页遮挡映射；原 Flags0/Flags1 的完整数据输入和各装备选择尚未全部恢复。缺口保留，不凭外观猜补。
