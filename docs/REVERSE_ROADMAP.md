# 逆向目录与执行记录

目标：以现有3.1.3a APK及用户提供的资源为证据，逐步重建可在本地联机游玩的浏览器版本。1:1是核对目标，不把网页替代规则当作原版行为。原服务器代码、缺失素材与未观察到的服务端判定不会凭空补成“已恢复”。

## 自主推进约定

用户已授权：按目录连续分析、接入、测试、修复并在本地验证后同步GitHub，无须为每个普通实现步骤再次询问。每个工作项依次完成：

1. 记录原文件版本、调用地址/字段和校验指纹，分清已证实、推断、网页适配。
2. 先确定适用分支，再接入服务器判定及客户端显示；原素材和存档留在忽略目录。
3. 运行相关格式、算法及真实双连接测试；涉及画面/输入则做浏览器验收。
4. 核对原角色进度和资源版本，更新记录，通过后提交/推送并核对该提交的CI。
5. 继续下一项。缺少某项证据时记录具体缺口，继续不依赖它的工作，不用猜测值宣称还原完成。

新服务器部署、修改朋友的正式数据库、公开原资源和不可恢复的数据操作不属于这个普通开发队列。需要用户提供当前没有的文件或原客户端观察时，一次说明具体缺口。
