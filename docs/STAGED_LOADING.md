# 新手区域分阶段加载

同日后续：[移动延迟与边走边加载核查](MOVEMENT_AND_STREAMING.md)记录边界等待的复现与修正。下面是首轮 25 块先行的历史结果；后续保留显示范围，额外预备相邻一圈，并调整宿主输入发布和画面缓冲。

2026-11-13，接续[无损压缩与缓存](ASSET_DELIVERY.md)。本轮只调整浏览器素材准备顺序：入场范围先完成，远处地形与建筑在后台准备。不改服务器、战斗、碰撞、存档、角色选择、地图数据、材质、光照、界面布局和美术。自动任务 2 保持暂停。

## 范围怎样确定

历史预览的 `explore-map.js` 已使用 `sourceArchiveWindow` 决定附近哪些对象显示，但之前仍等 251 块地形、158 种场景模型全部准备完才解除进入按钮。本轮复用它现有的区块中心算法、25 个请求偏移、半径 2 和保留范围，先准备当前入场窗口。没有另设视距，没有用包围盒或名字猜哪些建筑可以省掉。

当前演示入口的实际中心为 `[-41,2]`：25 块地形、53 种建筑模型，其实例仍使用原摆放、材质与绑定函数。其余 226 块地形及相关建筑在后台补齐，完成后覆盖、实例和材质数量与上一版一致。这个中心来自**当前历史预览的演示坐标映射**，不是新发现或恢复出的原手游开局位置；原入图坐标缺口保持。

角色、怪物、可立即使用的战斗资源、UI，以及现有初始化共同消费的水面、光照资料，保守地放在入场阶段。水面和光照不拆、不换近似材质，因而这还不是下载量的理论最小值。817 个预取 URL 优先，517 个其余 URL 在原进入条件满足后以较低并行数下载；相同内容仍按 SHA 缓存复用。

## 修改边界

- `deploy/stage_runtime.mjs`：先严格核对已有入口 SHA，再生成只调整加载段与完整窗口呈现检查的独立副本；锚点变化则拒绝启动，不用宽松文本匹配。原私有包和 127 份已核对运行文本不覆盖。**浏览器收到的一份入口有明确的加载适配，不能再说所有送到浏览器的 JS 都与上一版字节相同。**
- `deploy/staged_scene.mjs`：仍调用现有的地形创建、模型加载、实例材质绑定函数。首批完成即可进入；后台每次最多准备两个区块，并让出浏览器执行时间。共享模型只加载一次，不创建临时几何或缺省贴图，也不改任何原数据内容。
- `deploy/stage_plan.mjs`：从当前地图清单、入口坐标映射及 JSON 引用生成入场/后台预取计划；完整水面初始化实际消费的依赖仍保留。清单变化就重新计算，不把角色存档读入公开计划。
- `deploy/delivery_boot.mjs`、`deploy/delivery_worker.mjs`：入场优先 12 路、其余预取 4 路，保留上一轮的无损压缩、校验、缓存及旧版计划兼容。引导会确认工作线程支持新计划；旧线程仍控制页面时等待新版接管，避免更新瞬间把分阶段计划当作旧列表。

若移动或恢复角色后需要的窗口尚未完整准备，提升相关准备任务优先级，保留上一张完整画面，等待该窗口齐备才提交下一张；不会绘制漏建筑、缺地面的中间状态。服务器仍继续原本的移动/碰撞/状态同步，不修改坐标、不加空气墙。极慢网或后台文件失败时，这可能表现为短暂停画；失败保留诊断，不用替代资源解除检查，刷新可重新加载。后台完成后不会额外卸载或删除原有内容。

## 本地验证

在隔离 Linux 容器与独立测试存档中，对照上一轮压缩/缓存版本。每请求同加 80ms 延迟，不限带宽；统计到原进入按钮解除禁用。首轮上一版 16.30 秒/65,202,114 字节，新版 11.33 秒/54,615,422 字节；最终镜像结果和刷新原始记录留在本地交接。不是公网性能承诺。

额外把“后台专有”文件延迟至导航后 45 秒才释放：仍约 11.5 秒完成入场。实际点击进入时地形 25 块、后台 0/226、145 个已准备的普通场景材质；角色从 Z182.0 行走到 Z186.8，附近窗口保持完整，跳跃按钮仍由原控制器处理。解除诊断延迟后后台可继续完成。该人为延迟只在回环测试代理，不进 Railway 游戏。

实际正常游玩跨过 Z192 的区块边界，中心由 `[-41,2]` 变到 `[-41,3]`，沿用原保留范围；两浏览器同图观察与按键移动通过。完整加载后仍为 251 地块、401 普通材质、30 裁切材质。相同入场截图的 217,300 个静态场景像素逐 RGB 对照差为 0；角色/动作不作为静态像素断言。旧还原缺口未因此消失，也不称全图像素级 1:1 验收。

传输与分阶段检查共 24 项本地通过，包括后台专有资源不会提前预取、完整覆盖、窗口等待、返回已完成范围不被远处拖住、失败不显示占位物、未知入口拒绝适配、原服务器/移动/角色更新代码段保持。公开 CI 缺私有入口时只跳过该项原文件复核，其他用自有夹具执行。8 项部署边界检查通过；2537 个公开文件和 882 份压缩副本全量字节核对通过。双 WebSocket 原碰撞移动/装备广播、重建最终镜像后的角色位置/物品/装备恢复通过。

首轮自动点击早于资源就绪而超时、跳跃 AX 角色选择与实际 DOM 不同，以及最后一次重建时恢复检查早于健康就绪的失败都保留日志；等待原就绪/服务健康信号、改用原按钮定位后完成真实交互与恢复核对，没有改游戏绕过失败。
