## 当前入口

双击项目根目录的 `启动本地MVP.command`，或在项目目录执行：

```sh
./启动本地MVP.command --check
./启动本地MVP.command
```

当前已启动的地址：`http://127.0.0.1:8876/explore-map.html?room=MVP-01&sourceProfile=APK_Default`。

默认单人可进入，每房间上限 8；当前两人展示。修改上限不改玩家模型、地图、移动或战斗代码：


## 多人接口

- 服务工厂增加 `createGameServer({maxPlayersPerRoom})`，默认 8，接受 1–32。上限属于本地运行配置，不是恢复出的原版服务器限制。
- `welcome.roomCapacity` 通知客户端，原有隐藏营地面板的人数显示读取该值，不写死双人或 8。
- 玩家仍按角色 ID 放进同一个 `Map`，移动/战斗/广播遍历集合。出生序号复用空槽，与八种显示颜色分离；超八人时颜色可重复，不会得到旧 `-1` 序号。
- 房间容量在创建角色前检查，满员拒绝不新增角色。服务器总连接门限仍为现有 128；这不是负载能力承诺。
- 当前用四个真实连接检查扩展路径。32 只是配置校验范围，未做 32 人原物理/渲染性能验收，不声称已支持该负载。

这些是保持网页接口可扩展的接线，不修改原地图或原角色规则。受控仓库只增加启动/核对工具和有边界的修改器，未把历史自写服务器称作原版源码。
